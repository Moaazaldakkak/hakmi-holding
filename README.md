## Current Deployment

The under-construction page is live at the root domain. The `under-construction/` folder contains the complete standalone page with:
- Responsive design (mobile/desktop)
- Notification signup form (POST to `send-email.php`)
- Privacy Policy & Terms of Service modals
- Custom Lyon Arabic Display fonts
- SVG favicon and logo assets

## Future Structure

When the main site is ready, it will be added at the repository root or in a `website/` folder, with the under-construction page moved to a subdomain or removed.
